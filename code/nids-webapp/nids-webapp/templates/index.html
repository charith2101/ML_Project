How it works

  1. Dataset: NSL-KDD (Train_data.csv) – 25,192 connection records, 41 features, label normal / anomaly.
  2. Preprocessing: categorical features (protocol_type, service, flag) are label-encoded; all features are standardised with StandardScaler (fit on the training split only).
  3. Split: 80% train / 20% test, stratified so both keep the same normal/anomaly ratio.
  4. Random Forest: 200 decision trees voting together; gives interpretable feature importances.
  5. Deep Neural Network: dense layers 128 → 64 → 32 → 1 (sigmoid), dropout 0.3, Adam optimiser, early stopping.
  6. Prediction: each model outputs a probability that the connection is an intrusion; ≥ 50% is flagged as anomaly.
